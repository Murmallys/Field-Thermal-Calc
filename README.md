# Сервис расчёта энергопотребления и теплового режима полевых пунктов управления с учётом климатических условий и теплофизических свойств материалов

## 📋 Описание

Десктопное приложение для расчёта энергопотребления и теплового режима полевых пунктов управления (ППУ). Программа позволяет:

- Создавать проекты с заданием состава объектов и климатических условий
- Рассчитывать теплопотери через ограждающие конструкции
- Подбирать оборудование (генераторы, отопители, кондиционеры) из единой базы знаний
- Формировать отчёты в формате PDF

Приложение ориентировано на работу в среде **Astra Linux** и на **Windows**.

## Стек технологий

| Компонент | Технология |
|-----------|-----------|
| Язык | Python 3.10+ |
| UI-фреймворк | PyQt6 |
| База данных | SQLite |
| Математические расчёты | NumPy, Pandas |
| Генерация отчётов | ReportLab |
| ORM | SQLAlchemy |
